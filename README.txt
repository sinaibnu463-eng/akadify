AKADIFY LANDING PAGE

FILES
- index.html       Main landing page
- assets/akadify-logo.png
- assets/favicon.png
- robots.txt

UPLOAD
Upload index.html, robots.txt, and the entire assets folder to the public web root of your hosting (often public_html or www).
Keep the assets folder beside index.html so the logo and favicon load correctly.

IMPORTANT
The website uses only static HTML/CSS/JS. No database or backend is required.

BEFORE PUBLIC LAUNCH
- Replace/add a canonical URL and Open Graph image URL after the final domain is known.
- Add a privacy policy if you collect personal data through future forms.
- Test WhatsApp, Instagram, and email links on the live domain.
